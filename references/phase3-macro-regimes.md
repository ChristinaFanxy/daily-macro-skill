## 3.1 核心资产相关性矩阵

| 资产对 | 正常相关性 | 逻辑基础 |
|--------|------------|----------|
| 美债10Y vs 黄金 | 负相关 | 实际利率↑ → 持有黄金机会成本↑ |
| 美元(DXY) vs 黄金 | 负相关 | 美元计价，美元强则黄金弱 |
| 油价 vs 美债收益率 | 正相关 | 油价↑ → 通胀预期↑ → 收益率↑ |
| VIX vs 股市(SPX) | 负相关 | 恐慌↑ → 股市↓ |
| 日元 vs 风险资产 | 负相关 | 避险情绪 → 日元↑，风险资产↓ |
| 铜 vs 全球增长预期 | 正相关 | 铜是经济风向标 |
| 2s10s利差 | 需区分驱动端 | 见下方拆分规则 |

### 2s10s 曲线形态拆分规则

| 形态 | 驱动端 | 判定条件 | 宏观含义 |
|------|--------|----------|----------|
| **Bear Steepener (熊陡)** | 10Y↑ 主导 | 10Y涨幅 > 2Y涨幅 | 再通胀/过热，通胀预期上升 |
| **Bull Steepener (牛陡)** | 2Y↓ 主导 | 2Y跌幅 > 10Y跌幅 | 衰退/恐慌降息预期 |
| **Bear Flattener (熊平)** | 2Y↑ 主导 | 2Y涨幅 > 10Y涨幅 | Fed加息周期 |
| **Bull Flattener (牛平)** | 10Y↓ 主导 | 10Y跌幅 > 2Y跌幅 | 避险/增长担忧 |

## 3.2 四大宏观体制

基于 **增长 (Growth)** vs **通胀 (Inflation)** 的四象限模型：

### A: 金发姑娘 (Goldilocks) — 增长↑ + 通胀↓

| 资产 | 预期方向 | 逻辑 |
|------|----------|------|
| 股市 | ↑↑ 狂欢 | 盈利增长 + 估值扩张 |
| 美债收益率 | 震荡/微降 | 通胀无压力，Fed偏鸽 |
| 信用利差 | 收窄 | 风险偏好上升 |
| 黄金 | ↓ | 无避险需求，机会成本高 |

**典型背离**: 股市↑ 但 信用利差走阔 → 警惕：聪明钱在撤退

---

### B: 再通胀 (Reflation) — 增长↑ + 通胀↑

| 资产 | 预期方向 | 逻辑 |
|------|----------|------|
| 铜/油 | ↑↑ 大涨 | 需求拉动型通胀 |
| 美债收益率 | ↑ 陡峭上行 | 通胀预期 + 增长预期 |
| 周期股 | 跑赢成长股 | 盈利弹性大 |
| 新兴市场 | ↑ | 商品出口国受益 |

**典型背离**: 铜↑ 但 股市↓ → 成本推动而非需求拉动，警惕利润率压缩

---

### C: 滞胀 (Stagflation) — 增长↓ + 通胀↑ 🔴 最危险

| 资产 | 预期方向 | 逻辑 |
|------|----------|------|
| 现金 | 为王 | 几乎所有资产都亏钱 |
| 黄金 | ↑ | 唯一的避风港 |
| 油价 | ↑ (供给冲击) | 通胀源头 |
| 美债收益率 | ↑ | 通胀压力 > 避险需求 |
| 股市 | ↓↓ 大跌 | 盈利下修 + 估值压缩 |
| 美元 | 不确定 | 取决于相对经济表现 |

**🔴 核心识别特征 (按权重排序):**
1. **最高权重**: 股债双杀 (SPX↓ + 10Y Yield↑) — 这是滞胀的本质特征
2. **高权重**: 大宗商品上涨 (油价↑, 铜↑)
3. **次要参考**: 美元方向 — 可强可弱，取决于美国 vs 其他经济体的相对表现
   - 2022年: 美元强 (欧洲能源危机更严重)
   - 1970年代: 美元弱 (美国自身滞胀)

**⚠️ 修正**: 不再使用"油价↑ + 美元↑ = 滞胀"的简化判断

**典型背离**: 黄金↓ 在滞胀环境 → 极端流动性危机（抛售一切换现金）

**⚠️ 滞胀特殊规则**:
- 必须提示: "当前滞胀环境下，股债可能同跌，传统 60/40 组合失效"
- 必须计算铜金比 (Copper/Gold)，比值下降 = 经济预期走弱

---

### D: 衰退 (Recession) — 增长↓ + 通胀↓

| 资产 | 预期方向 | 逻辑 |
|------|----------|------|
| 美债 | ↑↑ 暴涨 (收益率暴跌) | 避险 + 降息预期 |
| 黄金 | ↑ | 避险需求 |
| 股市 | ↓↓ 崩盘 | 盈利崩塌 |
| 原油/铜 | ↓↓ 暴跌 | 需求崩塌 |

**典型背离**: 美债↓ + 美元↓ 同跌 → 极度危险：美国信用担忧

---

## 3.3 背离检测流程

**Step 1**: 识别当前宏观体制 (Goldilocks/Reflation/Stagflation/Recession)

**Step 2**: 逐一检查资产方向是否符合体制预期

**Step 3**: 标记不符合预期的资产为潜在背离

**Step 4**: 验证背离显著性（使用混合阈值）

| 背离类型 | 显著性阈值 |
|----------|------------|
| 股市 vs VIX | SPX >0.5% 且 VIX同向 >5% |
| 美债 vs 黄金 | 10Y收益率 >5bp 且 黄金同向 >0.8% |
| 美元 vs 大宗 | DXY >0.5% 且 油/铜同向 >1.5% |
| 日元 vs 风险资产 | USD/JPY >0.8% 且 SPX同向 >0.5% |
| DXY vs 黄金同涨 | DXY >0.5% 且 黄金 >1% 同向上涨 |

**Step 5**: 对显著背离给出 2-3 个可能解释

## 3.4 七种背离模式

### 模式 1: 实际利率背离 — TIPS收益率(DFII10)↑ + 黄金↑
- **正常逻辑**: 实际利率↑ → 持有黄金机会成本↑ → 黄金↓
- **背离判定**: DFII10 上涨 >5bp 且 黄金同向上涨 >1%
- **⚠️ 注意**: 如果名义收益率(DGS10)↑但 Breakeven(通胀预期)↑更多，则实际利率↓，黄金↑是正常的，不是背离
- **宏观解释**: 真正的背离意味着市场在定价主权信用风险或极端通胀恐慌
- **危险等级**: ⚠️ 趋势反转信号
- **交易含义**: 警惕滞胀或主权信用担忧，考虑同时持有黄金和短久期债券
- **必须计算**: Breakeven = DGS10 - DFII10，判断通胀预期变化

### 模式 2: 期权异动 — SPX大涨↑ + VIX飙升↑
- **正常逻辑**: 股市↑ → VIX↓
- **宏观解释**: 极度FOMO，疯狂买入看涨期权
- **危险等级**: 🔴 **见顶前兆**
- **交易含义**: 高度警惕，随时可能反转

### 模式 3: 滞胀定价 — 股债双杀 (SPX↓ + 10Y Yield↑) + 大宗商品↑
- **核心特征**: SPX↓ + 10Y收益率↑ + 油价/铜↑ 同时发生
- **正常逻辑**: 股市↓ → 避险 → 收益率↓；或 收益率↑ → 经济向好 → 股市↑
- **背离现象**: 股债同时下跌（股市跌 + 债券价格跌/收益率涨）
- **宏观解释**: 供给侧冲击导致通胀上升但经济受损，央行被迫在"抗通胀"和"保增长"间两难
- **危险等级**: 🔴 **极度危险**
- **交易含义**: 利空几乎所有风险资产，现金为王，黄金可能是唯一避风港
- **⚠️ 注意**: 美元方向不确定，取决于美国 vs 其他经济体的相对表现

### 模式 4: 衰退确认 — 美债收益率暴跌↓ + 黄金暴涨↑
- **判定条件**: 10Y >10bp 且 黄金 >1.5% 同时剧烈波动
- **宏观解释**: 避险资金疯狂涌入安全资产
- **危险等级**: ⚠️ 衰退交易确认
- **交易含义**: 做多久期，做空周期股

### 模式 5: 流动性危机 — 黄金↓ + 股市↓ + 美债收益率↑ ☠️
- **前置条件**: 必须伴随 HY OAS 显著走阔 (>50bp 单日)，否则仅为技术性调整
- **正常逻辑**: 股市↓ → 黄金↑ 美债↑
- **宏观解释**: **极端恐慌导致"抛售一切"换现金**
- **危险等级**: ☠️ **最高危** (2020年3月、2008年雷曼)
- **交易含义**: 只有现金和短期美债安全，等待Fed救市

### 模式 6: 套息平仓 — USD/JPY暴跌↓ + 美股暴跌↓ + VIX飙升↑ 🔴
- **判定条件**: USD/JPY单日 >1.5% **且** VIX >20% 同时发生
- **⚠️ 排除条件**: 如果 USD/JPY 缓慢下行 + VIX 平稳 → 正常利差收窄，不是背离
- **前置检查**: 美日10Y利差是否在收窄？如果是，日元升值可能是正常的利差驱动
- **宏观解释**: **日元套息交易猛烈平仓**：卖美股 + 买回日元还债
- **危险等级**: 🔴 **连环爆仓预警**
- **交易含义**: 波动会自我强化，警惕踩踏
- **历史案例**: 2024年8月"黑色星期一"

**⚠️ 重要**:
- USD/JPY↓ = 日元升值
- 日元升值的原因可能是：(1) 避险情绪 (2) 美日利差收窄 (3) 套息平仓
- 只有 (1) 和 (3) 伴随 VIX 飙升，(2) 通常是温和的

### 模式 7: 铜金比背离 — 铜金比↓ + 美债10Y收益率↑ 🔍
- **正常逻辑**: 铜金比↑ = 经济乐观 → 收益率↑ (同向)
- **宏观解释**: 债市预期经济向好，商品市场预期衰退，**必有一方认错**
- **危险等级**: 🔍 **寻机信号**
- **交易含义**: 观察后续数据验证哪方正确
- **验证方法**: 关注PMI、工业产出等实体经济数据

### 模式 8: 法币信用对冲 — DXY↑ + 黄金↑ 同涨 ☠️
- **正常逻辑**: 美元强 → 黄金弱 (美元计价效应)
- **背离判定**: DXY >0.5% 且 黄金 >1% 同向上涨
- **宏观解释**: 资本同时抢筹美元（终极流动性）和黄金（终极避险/抗法币贬值），市场在对冲"所有法币"风险
- **危险等级**: ☠️ **极高危尾部风险**
- **交易含义**: 极端避险模式，警惕系统性风险，考虑增持实物资产
- **历史案例**: 2020年3月初期、部分地缘危机时刻

## 3.5 强制约束

**1. 资产计价方式约定**
- "日元" → 参考 USD/JPY (↓=日元升值=Risk-Off)
- "美债" → 参考收益率 (↓=债券价格↑=避险)

**2. 噪音过滤**
- 只有超过显著性阈值才触发背离判定
- 微小波动不属于背离
- 若不确定，宁可不报也不要误报

**3. 输出要求**
- 检测到背离 → 必须使用 `🚨 跨资产背离预警` 独立成段
- 必须加粗点出哪两个资产产生矛盾
- 必须说明可能被清算/爆仓的方向

**4. 无背离时**
- 简要提及"跨资产逻辑一致"即可
- 示例: "今日跨资产逻辑一致：油价上涨推升通胀预期，美债收益率上行，美元走强，黄金承压，符合典型的'滞胀交易'模式。"

**5. VIX 背离检测 (Brief 模式也必须)**
- 若地缘冲突/重大风险事件持续，但 VIX 显著回落 (>10%)，必须标注：
  > "⚠️ VIX 与风险事件背离：VIX 从 [X] 回落至 [Y]，市场恐慌边际消退，勿追高避险资产"
