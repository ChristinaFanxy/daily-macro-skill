# 4. 关注清单生成

## 4.1 关注点四大来源

| 来源 | 说明 | 示例 |
|------|------|------|
| **A: 核心矛盾衍生** | 从今日核心矛盾直接推导 | 地缘冲突→油价关键位、黄金避险位 |
| **B: 技术关键位** | 整数关口、前高前低 | 油价$70/$80、10Y 4.5%、DXY 105 |
| **C: 事件日历** | 今日数据/讲话/财报 | CPI 8:30 ET、Powell讲话 |
| **D: Pain Trade边界** | 拥挤仓位的清算触发点 | 期权隐含波动、Gamma Flip水平 |

### 💥 Pain Trade 数据获取方法

#### A. CFTC COT 持仓数据 (免费官方 API)

**CFTC Public Reporting API (Socrata):**
```bash
# Disaggregated Futures (推荐，更详细)
curl -s "https://publicreporting.cftc.gov/resource/72hh-t7tf.json?\$limit=10&\$order=report_date_as_yyyy_mm_dd DESC"

# Legacy Futures
curl -s "https://publicreporting.cftc.gov/resource/6dca-aqww.json?\$limit=10&\$order=as_of_date_in_form_yymmdd DESC"
```

**关键字段解读:**
| 字段 | 含义 | 用途 |
|------|------|------|
| `pct_of_oi_prod_merc_long` | 商业多头占比 | 套保方向 |
| `pct_of_oi_m_money_long/short` | 管理资金多/空占比 | 投机仓位 |
| `change_in_m_money_long/short` | 管理资金仓位变化 | 趋势判断 |

**商品代码 (market_and_exchange_names):**
- 原油: "CRUDE OIL, LIGHT SWEET - NEW YORK MERCANTILE EXCHANGE"
- 黄金: "GOLD - COMMODITY EXCHANGE INC."
- 铜: "COPPER-GRADE #1 - COMMODITY EXCHANGE INC."
- 美债10Y: "10-YEAR U.S. TREASURY NOTES - CHICAGO BOARD OF TRADE"

**更新频率:** 每周五发布 (数据截至周二)

**CSV 直接下载:**
```
https://www.cftc.gov/files/dea/history/fut_disagg_txt_2026.zip
```

#### B. 期权 Gamma 数据

**⚠️ 预计算 GEX 数据无免费 API**，需从期权链数据自行计算。

**Tradier API (免费 Sandbox):**
```bash
# 获取期权链 (需注册获取 API token)
curl -H "Authorization: Bearer {TOKEN}" \
  "https://api.tradier.com/v1/markets/options/chains?symbol=SPY&expiration=2026-03-20"
```

**返回数据包含:** Greeks (delta, gamma, theta, vega), open_interest, bid/ask

**GEX 计算公式:**
```
GEX = Gamma × Open Interest × 100 × Spot Price²
```

**简化方案 (推荐):**
若无法获取实时 GEX，使用 WebSearch 搜索：
```
"SPY gamma exposure" site:spotgamma.com OR site:squeezemetrics.com
"[ticker] dealer positioning"
"options gamma flip level [ticker]"
```

**输出标注:**
- COT 数据 → 标注 `[CFTC COT T-3]` (数据滞后约3天)
- WebSearch 推断 → 标注 `[基于新闻推断]`
- 无法获取 → 标注 `[仓位数据暂不可用]`

## 4.2 关注点六大核心要素

每条关注点必须回答：

| 要素 | 必须明确 | 示例 |
|------|----------|------|
| 1️⃣ 标的 | 具体资产/数据 | WTI原油 |
| 2️⃣ 触发价位 | 具体数字 | $85支撑位 |
| 3️⃣ 催化剂/时间 | 什么事件/什么时候 | 今晚EIA库存 20:30 ET |
| 4️⃣ 顺势推演 | 突破后预期 | 跌破→下看$80 |
| 5️⃣ 证伪信号 | 反向情况预期 | 反弹$88→空头回补 |
| 6️⃣ 💥 Pain Trade | 哪个方向爆仓最严重 | 空头拥挤，反弹$90+将逼空 |

## 4.3 数量与质量要求

| 模式 | 数量 | 质量要求 |
|------|------|----------|
| `--brief` | 3条 | 每条1-2行 |
| `--full` | 4-5条 | 每条3-4行 |

**质量红线:**
- ❌ "关注油价走势" → ✅ "WTI $85支撑，跌破则下看$80"
- ❌ "美债可能波动" → ✅ "10Y突破4.50%→成长股压力"
- ❌ 只说突破 → ✅ 必须有双向逻辑

## 4.4 强制约束

1. **必须与核心矛盾挂钩**: 至少1条直接来自今日核心矛盾
2. **必须有具体数字**: 价格位、百分比或时间点
3. **必须有双向逻辑**: 突破/触发 + 反向/证伪
4. **💥 Pain Trade 必填 (Full模式)**: 至少1条包含仓位拥挤分析
5. **🔗 体制验证约束**: 至少1条用于验证/证伪当前宏观体制

**体制验证点示例:**
| 当前体制 | 验证/证伪观察点 |
|----------|------------------|
| Goldilocks | VIX突破[X] 或 信用利差走阔[Y]bp → 体制转向 |
| Reflation | 铜价跌破$[X] → 再通胀逻辑被证伪 |
| Stagflation | 油价跌破$[X] 且 美元走弱 → 滞胀压力缓解 |
| Recession | 铜价反弹[X]% → 衰退预期可能过度 |

# 5. 风险提示生成

## 5.1 风险分类

**按时间:**
| 类型 | 定义 | 示例 |
|------|------|------|
| 即时风险 (T+0) | 今日可能兑现 | 今晚CPI超预期 |
| 潜伏风险 (T+N) | 近期可能爆发 | 日元套息仓位拥挤 |
| 尾部风险 (Tail) | 低概率高影响 | 地缘冲突升级 |

**按来源:**
| 来源 | 监控指标 |
|------|----------|
| 叙事反转风险 | PHASE 2 证伪条件 |
| 仓位清算风险 | COT持仓、期权Gamma `[需WebSearch获取，标注数据来源]` |
| 流动性风险 | 假期前后、月末季末 |
| 相关性破裂风险 | 股债相关系数、黄金与美元同向 |

## 5.2 风险识别决策树

**Step 1: 从核心矛盾反推**
| 核心矛盾 | 对应风险 | 触发条件 |
|----------|----------|----------|
| 地缘冲突升级 | 意外缓和 | 停火/和谈 → 避险资产踩踏 |
| 央行鹰派 | 意外鸽派 | 措辞软化 → 空头回补 |
| 数据强劲 | 数据崩塌 | 大幅低于预期 → 衰退交易 |

**Step 2: 评估定价程度**
| 定价程度 | 判断标准 | 风险威胁 |
|----------|----------|----------|
| 未定价 | 市场共识相反，对冲成本极低 | ☠️ 极高 |
| 部分定价 | 有所防备，仓位未完全调整 | 🔴 较高 |
| 充分定价 | 利率期货/期权已反映 | ⚠️ 有限，可能"Sell the fact" |

**Step 3: 评估对冲成本**
| 状态 | 含义 | 信号 |
|------|------|------|
| 对冲极便宜 (IV低) | 市场麻痹 | 🎯 非对称盈亏比机会 |
| 对冲极贵 (IV高) | 聪明钱已防备 | ⚠️ 风险可能已定价 |

## 5.3 风险严重性评估

**评估维度 (1-4分):**
| 维度 | 低(1) | 中(2) | 高(3) | 系统性(4)☠️ |
|------|-------|-------|-------|-------------|
| 影响幅度 | 单一资产<1% | 多资产1-3% | 跨资产>3% | 全市场崩盘 |
| 传染性 | 局限单一资产 | 影响相关资产类 | 跨资产传染 | 相关性破裂 |
| 可逆性 | 日内可修复 | 需数日消化 | 可能改变趋势 | 不可逆转 |

**风险等级:**
| 最终分 | 等级 |
|--------|------|
| <5 | ⚠️ 一般风险 |
| 5-8 | 🔴 重大风险 |
| >8 | ☠️ 系统性风险 |

**🚨 一票否决**: 任一维度=4 → 强制归类为 ☠️ 系统性风险

## 5.4 风险提示六大要素

| 要素 | 必须明确 |
|------|----------|
| 1️⃣ 风险名称 | 一句话概括 |
| 2️⃣ 触发条件 | 什么情况下兑现 |
| 3️⃣ 定价程度 | 市场是否已防备 |
| 4️⃣ 影响与传导 | 直接冲击 + 二阶效应 |
| 5️⃣ 严重程度 | 风险等级 |
| 6️⃣ 应对建议 | 工具与方向 |

## 5.5 强制约束

1. **必须与核心矛盾对立**: 风险是核心矛盾的"反面"
2. **必须评估定价程度**: 未定价且对冲便宜 → 标注"🎯 非对称机会"
3. **必须有触发条件**: 禁止"市场可能波动"
4. **必须有影响资产**: 不能只说"风险资产"
5. **必须有应对建议**: 至少说明"规避"或"利用"方向
6. **二阶传导 (Full必填)**: 第一反应后的连锁反应
7. **相关性破裂预警**: 滞胀/流动性危机时提示"传统对冲可能失效"
8. **数量控制**: Brief 1条，Full 最多2条
