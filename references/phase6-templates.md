## 6.1 报告生成流程

```
Step 1: 模式判定 → --brief 或 --full，默认 --brief
    ↓
Step 2: 内容组装 → 按模板填充各PHASE输出
    ↓
Step 3: 置信度评估 → 基于跨资产一致性
    ↓
Step 4: 标签注入 → 体制/生命周期/预警标签
    ↓
Step 5: 质量检查 → 隐式运行检查清单
    ↓
Step 6: 元数据附加 → 时间戳、数据源、免责声明
```

## 6.2 标签系统

**A. 宏观体制标签**
| 标签 | 场景 |
|------|------|
| `🟢 Goldilocks` | 增长↑ 通胀↓ |
| `🟡 Reflation` | 增长↑ 通胀↑ |
| `🔴 Stagflation` | 增长↓ 通胀↑ |
| `⚫ Recession` | 增长↓ 通胀↓ |

**B. 生命周期标签**
| 标签 | 场景 |
|------|------|
| `[T+0 爆发期]` | 事件刚发生 <24h |
| `[T+N 僵持期]` | 事件已发生但未升级 |
| `[⚠️ Priced-in]` | 市场已充分定价 |
| `[缓和期]` | 出现缓和信号 |

**C. 预警标签**
| 标签 | 场景 |
|------|------|
| `🚨 背离预警` | 检测到跨资产背离 |
| `💥 Pain Trade` | 仓位拥挤风险 |
| `🎯 非对称机会` | 对冲成本极低 |
| `☠️ 系统性风险` | 一票否决触发 |

**D. 置信度标签**
| 标签 | 判断标准 | 建议 |
|------|----------|------|
| `🟢 高置信度` | 数据印证，无背离，核心矛盾清晰 | 正常配置仓位 |
| `🟡 中置信度` | 部分噪音，部分资产方向不明 | 降低仓位，等待确认 |
| `🔴 低置信度` | 严重背离，叙事混乱 | **多看少动** |

## 6.4 Full 模式模板

### Full 模式思维链要求 (必须)

在输出正式报告前，必须先输出 `<macro_reasoning>...</macro_reasoning>` 标签，包含：

1. **质量检查清单逐条回答** — 核心内容、关注清单、风险提示、跨资产一致性
2. **核心矛盾沙盘推演** — 如果核心矛盾被证伪，市场会如何反应？
3. **跨资产背离检测** — 逐一检查8种背离模式是否触发
4. **曲线形态判定** — 当前是 Bear/Bull Steepener/Flattener？

完成思维链后，再输出 Markdown 格式的正式报告。

```markdown
# 📊 每日宏观策略报告 | [宏观体制标签]
```

## 6.6 强制约束

1. **TL;DR (Full必须)**: ≤30字，包含体制+动作+防范
2. **置信度 (Full必须)**: 标注后给一句话理由，🔴低置信度时提示"多看少动"
3. **模式区分**: Brief ≤500字精简，Full 详尽完整
4. **数据表格**: 数值对齐小数点，涨跌用+/-，缺失标注`[N/A]`
5. **禁止空洞**: ❌"市场波动加大" → ✅"VIX从15升至22，涨幅47%"
6. **因果链完整**: 发生了什么 → 为什么重要 → 影响什么
7. **时效性标注**: 数据滞后>1交易日 → 标注`[数据滞后 T-N]`
8. **语言**: 默认中文，技术术语可混用英文，用户英文提问则全英文
9. **免责声明**: 每份报告结尾必须有
10. **滞胀特殊规则**: 必须提示60/40失效，必须分析铜金比
11. **VIX背离检测 (Brief也必须)**: 地缘事件持续但VIX回落>10% → 标注Priced-in预警
